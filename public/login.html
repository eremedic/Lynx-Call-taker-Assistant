First time signing in, or forgot your password?

Call takers: ask an administrator to reset your password.

This is not your Supabase or Netlify login. Patient Intake has its own accounts. The first administrator's username is admin unless you set ADMIN_USERNAME.

Administrator locked out (Netlify): in Netlify → Environment variables set ADMIN_PASSWORD to a new password and add ADMIN_RESET = true, then redeploy. Sign in as admin with that password, choose a new one, and delete ADMIN_RESET.

Running it yourself: run npm run reset-password -- admin in a terminal in the project folder.
